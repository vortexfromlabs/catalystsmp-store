# Store fonts

`Minecraftia.ttf` (Andrew Tyler) is the bitmap face used for headings, prices and buttons so the
store reads like a real Minecraft UI.

Minecraftia is free for **personal** use only. A commercial licence must be purchased from
https://andrewtyler.net/fonts/ before this store is used commercially. If you would rather use a
fully open-licensed pixel face, drop in a replacement file here, keep the family name `Minecraftia`
or update `$heading-font-family` in `assets/styles/theme.scss` and the `--cat-font-heading` token in
`assets/styles/elements/_catalyst.scss`.
